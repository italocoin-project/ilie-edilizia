# Ilie Edilizia

Sito web professionale per servizi di edilizia, muratura e ristrutturazione.

## Avvio

Il sito è realizzato in HTML, CSS e JavaScript statici ed è pubblicabile tramite GitHub Pages.

## Personalizzazione

Prima della pubblicazione completa, sostituire i recapiti dimostrativi, aggiungere fotografie autentiche dei lavori e verificare i servizi effettivamente offerti.
